# HydroFamily

Небольшой веб-проект для учета питьевого режима семьи.

## Что внутри

- приветственный лендинг на главной странице;
- трекер воды для нескольких участников;
- расчет дневной нормы по формуле `30 мл x 1 кг веса`;
- быстрые действия (`+/- глоток`, `+/- стакан`);
- общий прогресс семьи;
- кнопки `Сбросить день` и `Очистить всех`;
- favicon и Open Graph мета-теги для предпросмотра ссылок;
- сохранение данных в `localStorage`.

## Структура проекта

- `index.html` - страница лендинга и трекера;
- `assets/styles.css` - стили интерфейса;
- `assets/app.js` - логика трекера;
- `H2O.html` и `трекер воды.html` - старые версии макета.

## Запуск

1. Откройте файл `index.html` в браузере.
2. Добавьте членов семьи в форму.
3. Отмечайте выпитую воду кнопками на карточке участника.
